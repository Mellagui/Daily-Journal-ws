# Contributing to Daily Journal Website

Thank you for your interest in improving the **Daily Journal** official showcase website!

---

## 🚀 Getting Started

### Local Development
This website is built with vanilla HTML5, CSS3 (Glassmorphism design tokens), and modern JavaScript. No complex build tools, compilers, or heavy node modules are required.

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/Mellagui/Daily-Journal-ex-Website.git
   cd Daily-Journal-ex-Website
   ```

2. **Run Locally**:
   You can open `index.html` directly in your browser, or serve it using any local HTTP server (such as Python's HTTP server, VS Code Live Server, or `npx serve`):
   ```bash
   # Using Python 3
   python -m http.server 3000

   # Or using npx serve
   npx serve .
   ```
   Open `http://localhost:3000` in your web browser.

---

## 🎨 Design & Code Guidelines

- **Vanilla Stack**: Pure HTML, CSS, and JS. Keep assets lightweight and fast.
- **Glassmorphism & Color Harmony**: Maintain the coral cover gradient (`#FF6B4E` to `#F03D2B`), golden amber accents (`#FBBF24`), and dark/light mode CSS variables.
- **Responsive Layout**: Ensure layouts are fully responsive across desktop, tablet, and mobile screen sizes.
- **Accessibility & SEO**: Use semantic HTML tags, accurate meta tags, and descriptive `aria-label` attributes.

---

## 🌿 Submitting Pull Requests

1. Fork the repo and create your feature branch:
   ```bash
   git checkout -b feature/improve-landing-page
   ```
2. Commit your changes:
   ```bash
   git commit -m "feat: add interactive theme preview"
   ```
3. Push to your branch and open a Pull Request.
